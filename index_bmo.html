Google Colab HTDemucs 4-Stem Script & PPT Formula Reference

Run this 1-cell Python script in Google Colab to split any MP3/WAV into 4 isolated WAV stems

Quick Workflow for Your Demo Songs

1. Paste the script below into a Google Colab cell and run it. Upload your MP3/WAV song when prompted.

2. Demucs (`htdemucs`) will separate your track into vocals.wav, bass.wav, drums.wav, and other.wav and download a `.zip` archive.

3. Extract the `.zip` folder on your PC and click "Load Demucs Stem Folder" in the top bar.

Google Colab Python Script (Meta AI HTDemucs 4-Stem) 
# 1. Install Meta AI Demucs cleanly on modern Python 3.12/3.13 Colab
!pip install -q -U demucs

import os, shutil
from google.colab import files

print("Select an MP3 or WAV song from your computer:")
uploaded = files.upload()

if uploaded:
    song_filename = list(uploaded.keys())[0]
    song_name = os.path.splitext(song_filename)[0]

    print(f"Separating 4 stems for: {song_filename} ...")
    !demucs -n htdemucs "{song_filename}"

    stems_dir = f"separated/htdemucs/{song_name}"
    zip_name = f"{song_name}_demucs_4stems"
    shutil.make_archive(zip_name, 'zip', stems_dir)

    print("Downloading 4 isolated stems zip...")
    files.download(f"{zip_name}.zip")

Core DSP Equations

1. Short-Time Fourier Transform (Spectral Branch):
X[m, k] = Σ_{n} x[n] · w[n - mH] · exp(-j · 2πkn / N)

2. HTDemucs Hybrid Time-Frequency Dual U-Net Reconstruction:
x̂_s[n] = Decoder_time(Z_time) + iSTFT{ Mask_s(t, f) ⊙ X(t, f) }

3. Dual-Head Overlap-Add (OLA) Karaoke Pitch Shifting:
α = 2^(Δs / 12), y_ola[n] = w_A[n]·x[n - d_A[n]] + w_B[n]·x[n - d_B[n]]

4. 4-Stem Linear Mixing & Logarithmic Decibel Gain:
y_master[n] = g_master · (g_voc·x_voc[n] + g_bass·x_bass[n] + g_drum·x_drum[n] + g_other·x_other[n]), G_dB = 20·log10(g)
